name: swiss-ui-architect
description: Aplica el Estilo Tipográfico Internacional a componentes React/Tailwind con rigor de diseño sénior.
Procedimiento
Sistema de Rejillas: Implementa un Layout asimétrico usando CSS Grid. Usa variables para gutters y margins consistentes. 

Escala Tipográfica: Configura una escala basada en 'rem' usando la fuente 'Inter'. La jerarquía visual debe ser obvia y matemática. 

Tokens de Diseño: Crea un archivo de configuración de Tailwind que limite la paleta a: Blanco, Negro, Grises técnicos y un Rojo Suizo (#E04038) para acentos. 

Interactividad Minimalista: Implementa micro-interacciones sutiles (hover, transiciones suaves) que no distraigan de la información.
